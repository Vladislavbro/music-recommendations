# BLE Beacon Nearest

Android-приложение для демонстрации работы технологии обнаружения устройств в заведении через Bluetooth-маяки (BLE Beacon).

## Как работает эта демонстрация:

- необходимо вставить MAC-адрес необходимого BLE-маяка в приложение;
- выбрать название и цвет BLE-маяка (к примеру "ТАНЦПОЛ",красный и "БАР", синий);
- сохранить выбранные маяки в приложении;
- приложение сканирует BLE-устройства;
- показывает название сохраненного маяка с самым сильным свежим сигналом;
- окрашивает верхнее окно в выбранный цвет найденного маяка;
- хранит список маяков локально в `SharedPreferences`.

## Сборка приложения

```sh
./gradlew assembleDebug
```

APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.
